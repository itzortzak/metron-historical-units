# ΜΕΤΡΟΝ

Η δημόσια εφαρμογή είναι διαθέσιμη στο
[itzortzak.github.io/metron-historical-units](https://itzortzak.github.io/metron-historical-units/).

Διαδραστικός μετατροπέας ιστορικών και σύγχρονων μονάδων για μήκος,
επιφάνεια, μάζα και χωρητικότητα. Η διεπαφή είναι στα ελληνικά και ξεχωρίζει
τις ακριβείς σύγχρονες σχέσεις από τις κατά προσέγγιση ιστορικές
ανακατασκευές.

## Περιεχόμενο

- αττικές, αιγινητικές και ρωμαϊκές μονάδες μαζί με SI, διεθνείς και
  αγγλοσαξονικές μονάδες,
- εναλλακτικές ιστορικές παραδοχές, όπως ο βραχύς και ο μακρός αττικός πούς,
- αναζήτηση στον κατάλογο μονάδων, γρήγορα παραδείγματα και αντιμετάθεση,
- ελληνική και διεθνής γραφή αριθμών,
- επεξηγήσεις αβεβαιότητας και σύνδεσμοι προς τις βασικές πηγές.

Οι ιστορικές τιμές δεν παρουσιάζονται ως απόλυτες. Οι μετατροπές βασίζονται
στο υλικό του project «Historical Units» και διασταυρώνονται, μεταξύ άλλων,
με το *Athenian Agora X*, την Treccani, το BIPM και το NIST.

## Τοπική εκτέλεση

Απαιτείται Node.js 22.13 ή νεότερο.

```bash
npm install
npm run dev
```

Για έλεγχο παραγωγής:

```bash
npm test
npm run lint
```

Ο ιστότοπος βασίζεται σε Next.js/React και vinext και είναι έτοιμος για
δημοσίευση μέσω OpenAI Sites.

Η έκδοση GitHub Pages δημιουργείται ως ξεχωριστό static export και
δημοσιεύεται αυτόματα από το workflow του repository.
